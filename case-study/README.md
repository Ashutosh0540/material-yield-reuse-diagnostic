# Case study: Material Yield & Reuse Diagnostic

## Context

This case study frames an FDE engagement for a structural steel fabrication operation. The client is intentionally anonymous. No client name, confidential records, measured result, or completed implementation is represented in this repository.

## Supplied context and evidence status

The case framing supplied for this assessment says the client expressed interest in AI-powered nesting optimisation. Discovery was described as surfacing possible themes involving material yield and waste, reusable remnants/offcuts, drawing revisions, project allocation, yard accessibility, and existing STRUMIS capabilities. These themes are user-provided context, not independently verified findings in this repository.

The investigation would map how material requirements are fulfilled, how remnants are recorded and controlled, and how revisions, allocation, access, and existing tools shape decisions. Whether there is a measurable opportunity and what causes it remain unknown.
